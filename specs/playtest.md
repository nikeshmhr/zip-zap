# Zip Zap — Playtest Guide (T7.6)

Goal (spec AC 1): **every new player completes level 0.1 without outside help.** Aim for 3+ players who haven't seen the game.

## Setup

- A desktop browser, the game at a fresh profile (or **Settings → Reset progress**) so they start at 0.1.
- Sit beside or behind them, or share a screen. Record notes, not video, unless they agree.

## What to say

> "This is a puzzle game about building a computer from switches. I'm testing the game, not you. Please think out loud: say what you're trying, what you expect and what surprises you. I won't help unless you're completely stuck for a few minutes."

Then stay quiet. If they're stuck for more than ~3 minutes, ask "What are you trying to do?" before giving any hint, and note that you intervened.

## Session (30–40 minutes)

1. Level **0.1** from the very start (concept card included). **Record whether they finish unaided.**
2. Continue through chapter 0 and as far into chapter 1 as time allows.
3. Optional, for experienced players: jump to a memory level (4.2 or 4.3) using a test save.

## What to watch for

| Moment           | Note                                                                    |
| ---------------- | ----------------------------------------------------------------------- |
| First 60 seconds | Do they read the concept card? Do they find the toolbox and the canvas? |
| First wire       | Do they discover drag-from-pin? How many tries?                         |
| 0.1 refusal      | Do they understand "inputs can only drive relay coils"?                 |
| Running tests    | Do they find **Run tests**? Do failing rows make sense?                 |
| Hints            | When do they open them, and do they help or give it away?               |
| Chips            | Do they notice the unlocked chip in the next level?                     |

## After the session

Ask: _What was confusing? What was satisfying? Would you keep playing?_
